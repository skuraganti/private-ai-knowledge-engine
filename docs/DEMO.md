# Folio browser demonstration

Serve `docs` with a static HTTP server or use the published Pages URL. The full Python/Docker application and its startup instructions are in the [source repository](https://github.com/skuraganti/private-ai-knowledge-engine).

The browser searches the supplied original NIST passages lexically and displays exact excerpts with physical pages and official PDF links. The extractive answer quotes up to three matching passages and abstains when there are no matches; it is not generated or verified synthesis. Hiding a document affects only this page and removes it from the current results/answer; Restore all restores the fixture view.

The full-application lexical, latent and hybrid benchmark measurements are displayed as recorded, with n=12 and no claim of hybrid superiority. Sources: [NIST AI RMF 1.0](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf), [Generative AI Profile](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf), [SSDF 1.1](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-218.pdf).
