# API and integration contract

Factory create_app(db_path=None, prepared_dir=None,bridge_dir=None); lazy ASGI app, no state on import. Environment FOLIO_DB(defaultdata/folio.sqlite),FOLIO_PREPARED(defaultdata/prepared),FOLIO_BRIDGE(defaultdata/bridge). security.protect(app) supplies HTTP protection. One app process. Store operations use fresh SQLite connections/RLock transactions; safe on concurrent FastAPI threads. Source/version identity persistent; seed only first initialization, never revive deletion on restart. Prepared corpus manifest.json is a list of {id,title,url,pdf_name,sha256,publication,remote_allowed:true,pages:[{page:int,text:str}]}; only approved pinned-original manifests are remotely eligible, imports alwaysfalse. Read prepared file strict/bounded/regular-nonsymlink. No arbitrary file path/URL ingestion at runtime.
