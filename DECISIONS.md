# Decisions, failures and lessons

Actual development:2026-10-16.

- Chose three related original NIST reports over NASA's broader diagram-heavy handbook and Python's code-oriented documentation. Full bounded PDFs permit genuine page-linked evidence without credentials. Publication editions and later file-maintenance dates are recorded separately; third-party rights and extraction limits remain explicit.
- Used SQLite FTS5, local TF-IDF/SVD and rank fusion instead of Haystack's full pipeline, a vector service or downloaded neural weights. This fits the current Mac/VM and exposes understandable baselines. LSA is not a universal semantic model: hybrid tied lexical Hit@5 but had lower MRR, and a development definition question missed its source page. No held-out-specific ranking or prompt changes were made to hide that result.
- Chose claims with exact quote supports instead of free-form uncited prose. Invalid citations fail visibly. A safe abstention may still fail the user's information task; report both properties rather than treating every abstention as success.
- Kept imported/edited text local. Only independently matched snippets from three pinned public originals may enter approved inference. The bridge is a fixed host operation with no model tools, not an arbitrary-command endpoint. Native Skill calls observed in the primary worker included Karpathy, ECC FastAPI, Python testing and security review. Root separately applied evaluation/cost and verification guidance. No plugin installation is counted as execution evidence.
- Independent review reproduced DB/file crash and rollback windows, orphaned queue rows, oversized numeric metadata exceptions, source filtering after a global candidate limit, and a falsely healthy corrupt DB. Added nine direct regressions, deferred cleanup until commit, reconciled orphans without replay, bounded queue age, ordered numeric bounds safely, filtered before LIMIT and made health read the actual index.
- Integration found numeric-only usage validation incompatible with unavailable-cost metadata, and a version1-only bridge check incompatible with explicit restore. Kept unknown dollar billing in reports/UI, allowed later indexed versions only when excerpts still match the pinned originals, and verified a real cited answer from restored source version3.
- Moved the host call counter/control files outside the container-writable mount; fsync file and parent before inference. No automatic call retry, silent limit reset or provider switch. Exactly five live attempts were observed at acceptance; application calls and engineering-worker estimates are separate.
- First container creation failed because an unquoted flow-style tmpfs string split on commas (`invalid mount path: noexec`). Quoted the mount and verified the actual running container. No unrelated service was changed.
- Browser automation initially stopped at native confirmation dialogs, a persistent JavaScript variable collision and an assertion racing the new queued answer. Corrected/resumed the harness from saved UI state, retained those failures in the action log, and completed the real workflow without retrying model inference. Final checks found no browser errors and zero axe violations.

Alternatives/future experiments: heading-aware passage retrieval and a measured local neural-embedding baseline may improve definition queries, but require a fresh held-out set before tuning. Current acceptance reports the measured limitation rather than fabricated improvement. Auth, large multi-user libraries, arbitrary remote sources and compliance certification are outside this single-user local project.
